祁煜回忆相册｜上传说明

这个文件夹已经做好了，里面有：
- index.html（网站本体）
- p001.webp ～ p075.webp（全部 75 张照片）

GitHub 上传（一次就好）：
1. 打开你的仓库 Camyliaryne-ai / QiYu-memory。
2. 点 Add file → Upload files。
3. 把这个文件夹里的 index.html 和所有 pxxx.webp 全部一起拖进去。
   不要把外层 QiYu-memory-site 文件夹本身拖进去；要拖“里面的文件”。
4. 等上传完，点 Commit changes。
5. 进入 Settings → Pages。
6. Build and deployment 的 Source 选 Deploy from a branch。
7. Branch 选 main，右边选 /(root)，点 Save。
8. 等 1～3 分钟，Pages 页面会显示网站地址。

之后要加照片，也可以继续让我帮你更新相册文件。
